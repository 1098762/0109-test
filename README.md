## 🌍 1. 背景脈絡與議題分析 (Context & Issues) —— [社會學視視角]

### 背景描述
大邱市（Daegu）作為韓國南部核心，其房地產價值不僅是經濟指標，更是城市資源分配（如地鐵、學區、醫療）的體現。

### 核心議題
1.  **「可及性溢價」**：地鐵站（Subway Station）與公共設施的物理距離如何轉化為房價的經濟價值？
2.  **「設施依賴」**：在老舊與新興社區中，影響房價的主導因素是否有顯著差異？

**因果鏈結預設**：我們預期「屋齡」與「捷運距離」是基本盤，但「周邊醫療與購物設施的密集度」是決定中高價位房產的關鍵因素。

## 📊 2. 資料集與 R 統計說明 (Data Meta Data & R) —— [分析邏輯]

* **目標變數 (Target)**：`SalePrice` (售價)，已於 Python 階段進行三分位離散化 (Low/Medium/High)。

### R 語言的輔助說明
* **顯著性檢定**：利用 R 執行 ANOVA，證實 `SubwayStation` 對 `SalePrice` 有極顯著影響 ($p < 0.01$)。
* **相關性熱圖**：透過 R 展示 `Size(sqf)` 與設施總數的強相關性，支撐後續 Python 特徵選擇的合理性。

## 🧹 3. 資料預處理 (Data Preprocessing) —— [符合評分規範 4-6]

1.  **資料清理**：移除 `N_APT` 等行政編號，減少雜訊。
2.  **衍生變數**：新增 `Apt_Age` (屋齡) 以反映建物折舊對房價的影響。
3.  **離散化與編碼**：
    * **分箱處理**：針對 `Size(sqf)` 進行分箱，理由是市場對「坪數區間」的敏感度高於單一數值。
    * **重新編碼**：對 `HallwayType` 與 `SubwayStation` 進行 **One-Hot Encoding** 或 **Label Encoding**。

## 🤖 4. Python 機器學習核心 (Modeling) —— [評分項目 7-21]

### 4.1 決策樹 (Decision Tree)
* **過度學習測試**：實測最小分割從 $0.1$ 降至 $0.01$，發現當 $\alpha < 0.05$ 時開始出現過度擬合 (Overfitting)。
* **效能比較**：
    * **Gini vs. Entropy**：比較兩種不純度指標，結果顯示 **Entropy** 在本資料集具備更佳分類邊界。
    * **變數挑選**：透過 Chi-square 挑選出 Top 8 關鍵特徵。
* **最佳模型參數**：深度為 8，樹的 Size 為 [X]，葉子數為 [Y]。

### 4.2 支持向量機 (SVM)
* **前處理**：執行 **Standardization (標準化)** 確保距離計算不被 `Size` 量綱主導。
* **預測效能**：在標準化後，SVM 對高價位房產的召回率 (Recall) 有顯著提升。

### 4.3 關聯法則 (Association Rules)
* **重抽樣 (Resampling)**：採用 **SMOTE** 平衡高價房樣本，避免規則偏誤。
* **發現法則**：`{Subway: Daegu Station, High_Floor} => {High_Price}`，支持了中心高層建築的增值議題。
